# My Audio to Score

**My_A2S** is a deep learning system for audio to score (A2S), converting audio recordings directly into symbolic music notation in [ABC format](https://abcnotation.com/).

## Overview

Given an audio recording as input, it generates a structured ABC notation transcription as output — enabling downstream applications such as score editing, music analysis, and retrieval.
